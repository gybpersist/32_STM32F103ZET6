## 2. 系统定时器

### 2.1 概述

系统定时器一般用于操作系统，用于产生时基，维持操作系统的心跳。SysTick定时器除了能服务于操作系统之外，还能用于其它目的：如作为一个闹铃，用于测量时间等。

系统定时器是一个24bit的向下**递减**的计数器 ，自动重装载。

### 2.2 相关寄存器

| 寄存器名称    | 说明             | 相关控制位/标志位                                            |
| ------------- | ---------------- | ------------------------------------------------------------ |
| SysTick->CTRL | 控制和状态寄存器 | CLKSOURCE：时钟来源，0表示AHB/8; 1表示AHB<br>TICKINT: 中断使能<br>ENABLE: 计数使能<br>COUNTFLAG: 计数到0置位 |
| SysTick->LOAD | 重装载寄存器     | 24bit有效位，从这个数开始到计数                              |
| SysTick->VAL  | 当前值寄存器     | 24bit有效位，记录当前计数的值                                |

> 弱函数 HAL_IncTick() 每隔 1ms 被调用1次。

```c
// 重定义 SysTick 触发中断后调用的弱函数
void HAL_IncTick(void)
{
  // 保证 HAL_Delay 能够正常工作
  uwTick += uwTickFreq;

  // 每调用1000次该弱函数，LED2 翻转一次
  if (uwTick % 1000 == 0) {
    HAL_GPIO_TogglePin(LED2_GPIO_Port, LED2_Pin);  // 翻转 LED2
  }
}
```

### 2.4 案例： SysTick 中断方式实现延时函数工具类

#### 代码实现

```c
// 定义全局变量，用作延时的技术, 每隔1ms就递减1次,减到0为止
uint16_t g_ms_cnt = 0;


void Dri_SysTick_Delay_ms(uint16_t ms)
{
    // 赋值给延时的计数变量
    g_ms_cnt = ms;

    // 等待 g_ms_cnt 减到0为止
    while (g_ms_cnt > 0)
        ;
}

// 定义 SysTick 的 中断服务函数
void SysTick_Handler(void)
{
    // 延时计数递减
    if (g_ms_cnt > 0)
    {
        g_ms_cnt--;
    }
}
```





## 3. 基本定时器

### 3.1 概述

基本定时器TIM6和TIM7各包含一个16位自动装载计数器，由各自的可编程预分频器驱动。

这个2个基本定时器只能向上计数，由于没有外部IO，所以只能计时，不能对外部脉冲进行计数。

### 3.1 功能框图和功能描述

![%E5%9F%BA%E6%9C%AC%E5%AE%9A%E6%97%B6%E5%99%A8%E5%8A%9F%E8%83%BD%E6%A1%86%E5%9B%BE.png](https://p.sda1.dev/22/183938373451ec5aaa5ce3b21b54de4e/基本定时器功能框图.png)

**时钟来源：**

```
基本定时器时钟来源只有系统时钟， 只要 APB1 进行大于1的分频，TIMxCLK = APB1 * 2;
当前 APB1CLK = 36MHz, TIMxCLK = 72MHz
```

**时基单元：**

```
1. PSC 预分频器， 对 CK_PSC（等于TIMxCLK） 进行预分频产生 CK_CNT（计数器时钟）
2. CNT 计数器，向上计数，计到与自动重装载值相同，下一个周期溢出（触发更新事件中断）
3. ARR 自动重装载寄存器，分为预加载寄存器和影子寄存器，影子寄存器与CNT比较
```

### 3.3 相关寄存器

| 寄存器名称 | 描述                | 相关控制位/标志位                           |
| ---------- | ------------------- | ------------------------------------------- |
| CR1        | 控制寄存器1         | ARPE：自动重装载预装载使能<br>CEN：计数使能 |
| DIER       | DMA或中断使能寄存器 | UIE：更新中断使能                           |
| PSC        | 预分频器            | 16bit，这里的数值+1 作为与分频值            |
| ARR        | 自动重装载寄存器    | 16bit                                       |
| CNT        | 计数器              | 16bit                                       |
| SR         | 状态寄存器          | UIF: 更新中断标志位，需要软件清除           |

## 4. 通用定时器

### 4.1 概述

通用定时器有4个分别是：TIM2、TIM3、TIM4、TIM5；它们拥有基本定时器所有功能，并增加如下功能：

（1）多种时钟源。

（2）向上计数（加）、向下计数（减）、向上/向下（先加后减）。

（3）输入捕获。

（4）输出比较。

（5）PWM生成。

（6）支持针对定位的增量（正交）编码器和霍尔传感器电路。

### 4.2  功能框图和功能描述

![%E9%80%9A%E7%94%A8%E5%AE%9A%E6%97%B6%E5%99%A8%E5%8A%9F%E8%83%BD%E6%A1%86%E5%9B%BE.png](https://p.sda1.dev/22/f112793fbdf8b8ca8f4406fbc471d21a/通用定时器功能框图.png)

#### ① 时基单元（同基本寄存器）

```
预分频器寄 (TIMx_PSC) 
自动重装载寄存器 (TIMx_ARR) 
计数器寄存器(TIMx_CNT) 
```

#### ② 3种时钟源

```
1. 内部时钟源（通基本定时器）
2. 外部时钟源模式1：每个定时器有4个输入通道，通道1和通道2可以作为时钟信号源
3. 外部时钟源模式2：每个定时器的ETR引脚输入作为时钟信号源
```

#### ③ 3种计数模式

```
1. 向上计数模式（同基本定时器）
2. 向下计数模式
3. 中央对齐模式（先向上再向下）
```

| TIM3   | PA6/PB4/PC6  | PA7/PB5/PC7 | PB0/PC8  | PB1/PC9  | PD2          |

![%E9%80%9A%E7%94%A8%E5%AE%9A%E6%97%B6%E5%99%A8%E6%A1%88%E4%BE%8B1%E5%8E%9F%E7%90%86%E5%9B%BE.png](https://p.sda1.dev/22/f84784e96c6c0aa165b7a82856d1e69e/通用定时器案例1原理图.png)

#### ②  PWM 介绍

```
PWM: Pulse-width modulation, 脉冲宽度调制
惯性：被控制的电路要有一定的惯性，电路中负载的状态不会发生突变，比如电机断电了不会立即停止
周期：连续的两个上升沿或连续的两个下降沿之间的宽度（时间），用 T 表示
频率：周期的倒数，1s内有多少个周期
占空比：每个周期中高电平占比
```

#### ③ 通用定时器的输出比较

TIMx_CCMR1寄存器中的 OC1M[2:0] 可以配置通道1的 8 种输出比较模式：

| OC1M值 | 描述                       | 行为                                                         |
| ------ | -------------------------- | ------------------------------------------------------------ |
| 000    | 冻结模式                   | CNT和CCR比较结果不影响输出。                                 |
| 001    | 匹配时输出高电平(有效电平) | 当CNT=CCR，输出有效电平，再不改变。                          |
| 010    | 匹配时输出低电平(无效电平) | 当CNT=CCR，输出无效电平，再不改变。                          |
| 011    | 匹配时输出翻转             | 当CNT=CCR，则翻转输出。高->低，低->高。<br>输出结果是一个方波，频率为计数器的溢出频率的一半，占空比为 50% |
| 100    | 强制输出低电平             | 强制输出为无效电平，不受到CNT和CCR比较结果影响。             |
| 101    | 强制输出高电平             | 强制输出为有效电平，不受到CNT和CCR比较结果影响。             |
| 110    | PWM模式1                   | 向上计数时，当CNT < CCR1时输出有效电平，反之无效电平;  <br>向下计数时，当CNT > CCR1时输出无效电平，反之输出有效电平。 |
| 111    | PWM模式2                   | 向上计数时，当CNT < TIM时输出无效电平，反之输出有效电平；<br>向下计数时，当CNT > CCR1时输出有效电平，反之输出无效电平。 |

> 注意：这里推荐使用 PWM模式1！
>
> 默认高电平是有效电平！

#### ③ 寄存器方式实现

`Driver_TIM5.c` 驱动程序：

```
初始化函数：
	1. 对TIM5、GPIOA时钟使能
	2. 设置TIM5_CH2(PA1)为复用推挽输出
	3. 设置TIM5时基单元
	   3.1 设置CNT计数模式为向上计数（默认值）
	   3.2 设置PSC预分频值(设置为719，实现每10us计1个数)
	   3.3 设置ARR自动重装载值（故意设置为99，计数100次产生1次更新事件）
	4. 设置TIM5输出比较
	   4.1 设置TIM5_CH2通道为输出比较（CCMR1.CC2S=00,默认值）
	   4.2 设置TIM5_CH2的输出比较模式为PWM模式1 (CCMR1.OC2M=110)
	   4.3 设置TIM5_CH2的极性:有效电平为高电平 (CCER.CC2P=0,默认值)
	   4.4 设置TIM5_CH2输出使能(CCER.CC2E=1)

启动函数：计数器使能
	计数使能 (CR1.CNE = 1)

停止函数: 取消计数器使能
	关闭计数使能 (CR1.CNE = 0)

设置占空比的函数：
	设置CCR2的值
```

`main.c`主程序：

```
1. 初始化TIM6，设置每100ms产生一次更新事件；并让TIM6启动计数
2. 初始化TIM5，输出1KHz的PWM方波
3. 重定义TIM6更新中断所调用的弱函数
   修改TIM5所输出PWM的占空比，先递增到100，再递减到0，每次变化10，循环往复
```
