## 第 3 章 ADC（模数转换）

### 3.1 ADC 介绍

#### ① 概述

**ADC**： Analog to Digital Converter，模拟数字转换器。用于将模拟信号转换为数字形式，以便在数字系统中进行处理。

一般传感器会把观测的物理量转换为电压值，也就是所谓的**模拟信号**。计算机的世界里只有0和1，ADC转换器就是把模拟的物理量（电压值）转换为计算机认识的**数字量**。

#### ② ADC 工作原理

分为两个阶段：

**采样阶段**：ADC首先对模拟信号进行采样，即在一定时间内获取信号的**瞬时值**。

**量化阶段**：采样后的模拟信号通过量化器，将其转换为相应的**数字**形式，这个数字形式通常是**二进制**代码。

![ADC%E5%B7%A5%E4%BD%9C%E5%8E%9F%E7%90%86.png](https://p.sda1.dev/22/ee2e2f79a3ab3c0938cde4b83289c38a/ADC工作原理.png)

#### ③ ADC 主要参数

**参考电压（Reference Voltage）** ：

ADC 使用参考电压来确定模拟信号的幅度范围。通常，ADC 需要一个已知的电压作为参考，以便将模拟电压映射到数字代码。

**通道数（Number of Channels）** ：

  表示 ADC 能够同时处理的模拟输入通道的数量。  多通道 ADC 可以同时转换多个信号。

**采样率（Sampling Rate）** ：

  表示 ADC 每秒可以进行多少次采样。  采样率越高，ADC 的转换速率越高。

**转换时间（Conversion Time）** ：

  表示 ADC 开始转换到完成转换所需的时间。  转换时间通常由 ADC 的转换速率和分辨率决定。

**分辨率（Resolution）**： 

  表示 ADC 可以将模拟信号分成多少个离散级别。  ADC 的分辨率由数字信号的位数 N 来表示，一般有 10 位、12 位、16 位等。例如，12 位 ADC 有 4096 个离散级别。



### 3.2 STM32 中 ADC 功能框图和功能描述

STM32F103系列提供了3个ADC，精度为12位，每个ADC最多有16个外部通道和2个内部信号源。

各通道的A/D转换可以单次、连续、扫描或间断模式执行。ADC的结果可以左对齐或右对齐方式存储在16位数据寄存器中。模拟看门狗特性允许应用程序检测输入电压是否超出用户定义的高/低阀值。

#### ① 逐次逼近型ADC工作原理

**<font color="red">STM32F103 的 ADC 是一种逐次逼近型模拟数字转换器。</font>**

**常见的ADC类型有（了解）：**

```
1. 逐次逼近型 ADC（SAR ADC）：
   通过逐次比较逼近模拟信号的值，精度高，速度中等，广泛应用于中等速度和高精度的场景。

2. 积分型 ADC（双斜率 ADC）：
   通过积分和比较实现转换，速度较慢，但精度高，抗干扰能力强，常用于高精度测量（如电压表）。

3. 闪存型 ADC（Flash ADC）：
   通过并行比较器一次性完成转换，速度极快，但功耗和成本高，适用于高速低分辨率的场景。

4. Σ-Δ型 ADC（Sigma-Delta ADC）：
  通过过采样和噪声整形实现高精度，速度较慢，但分辨率高，适用于音频和高精度测量。

5. 流水线型 ADC（Pipeline ADC）：
  通过多级流水线结构实现高速高精度转换，适用于高速数据采集（如通信和视频处理）。
```

**逐次逼近型ADC工作原理：**

```
1. 采样保持：
   模拟信号被采样并保持在一个电容上，确保转换期间信号稳定。

2. 逐次比较：
   使用一个数模转换器（DAC）生成参考电压，与采样信号进行比较。
   从最高位（MSB）开始，逐位确定数字输出：比较器判断采样信号是否大于参考电压。如果大于，该位为1；否则为0。调整参考电压，继续比较下一位。

3. 数字输出：
   经过多次比较后，逐次逼近的结果即为最终的数字输出。
```

#### ③ 功能描述

##### ADC 输入时钟

ADC的输入时钟不得超过14MHz，它是由PCLK2经分频产生。

##### ADC 输入通道

```
用来输入模拟电压的通道
一共多达18个通道
16个外部通道（ADCx_IN0-ADCx_IN15），对应着16个IO口
2个内部通道
   ADC1的模拟输入通道16和通道17在芯片内部分别连到了温度传感器和VREFINT。
   ADC2的模拟输入通道16和通道17在芯片内部连到了Vss。
   ADC3模拟输入通道14、15、16、17与Vss相连
```

##### 通道组（序列）

````
规则通道组（Regular Channel）：序列中支持最多 16 个通道，使用 1 个数据寄存器（ADC_DR）存储转换结果。
注入通道组（Injection Channel）：序列支持最多 4 个通道，使用 4 个数据寄存器（ADC_JDR1 到 ADC_JDR4）分别存储每个通道的转换结果。
````

##### 中断

数据转换结束后，可以产生中断，中断分为三种：规则通道转换结束中断、注入通道转换结束中断、模拟看门狗中断。

```
1. 转换结束中断：ADC 转换完成后触发中断，通过中断标志位和使能位控制，可编写中断服务程序处理转换结果。
2. 模拟看门狗中断：当模拟电压超出设定的高阈值（ADC_HTR）或低于低阈值（ADC_LTR）时触发中断，用于监控电压范围异常。例如，电压超过 2.5V 或低于设定值时触发中断。
```

##### DMA 请求

规则通道和注入通道转换结束后，除了产生中断外，还可以产生DMA请求，把转换好的数据直接存储在内存里面。

> 注意：是只有 ADC1 和 ADC3 可以产生DMA请求。

##### 数据对齐

16位的寄存器只用到了其中的12位，可以使用高12位，数据就是左对齐；也可以使用低12位，数据就是右对齐。

##### 转换时间

ADC使用若干个ADC_CLK周期对输入电压采样总转换时间如下计算：

```
TCONV = 采样时间 + 12.5个ADC周期。
当ADCCLK=14MHz，假设采样时间为1.5周期。
TCONV = 1.5 + 12.5 = 14周期 = 1μs。
```

##### 电压转换

模拟电压经过ADC转换后，是一个12位的数字值，如果通过串口以16进制打印出来的话，可读性比较差，那么有时候我们就需要把数字电压转换成模拟电压。

将ADC转换后的12位数字值转换为模拟电压的公式为：
**Y = 3.3 × X / 4095**
其中：

- **Y** 是模拟电压值（单位：V）。
- **X** 是ADC转换后的12位数字值（范围：0~4095）。
- **3.3V** 是ADC的参考电压（满量程）。
- **4095** 是12位ADC的最大值（2^12 - 1）。

通过该公式，可以将ADC的数字值转换为实际的模拟电压，便于与万用表测量值对比，验证转换准确性。

### 3.4 案例1：独立模式单通道采集

#### ① 项目需求和硬件电路

```
采集可变电阻器的电压，并通过串口把电压数据发送到电脑端。
可变电阻连接单片机PC0，PC0是ADC的通道10
```

#### ② 寄存器方式实现

**ADC 驱动 Driver_ADC.c：**

```
初始化函数：
	1. 时钟使能和配置
		1.1 对GPIOC时钟使能
		1.2 对ADC1时钟使能
		1.3 设置ADCCLK进行6分频（RCC_CFGR.ADCPRE=10）
	2. GPIO 设置, 设置ADC1_IN10(PC0)为模拟输入
	3. ADC1 设置
		3.1 设置采样时钟 (SMPR1.SMP10)
		3.2 设置规则组长度（SQR1.L）
		3.3 将ADC1_IN10通道放入规则组第一个位置（SQR3.SQ1=01010）
		3.4 设置关闭扫描模式（CR1.SCAN=0, 默认值）
		3.5 设置开启连续模式（CR2.CONT=1）
		3.6 设置数据寄存器右对齐（CR2.ALIGN=0, 默认置）
		
开始转换函数：
	1. ADC唤醒: ADON为0的时候置1
	2. 开启校准，校准完成意味着稳定时间已经过去 (CR2.CAL)
	3. ADC启动转换：ADON为1的时候置1
	4. 等待ADC转换完成 (SR.EOC)
	
获取电压值函数：
	DR / 4095.0 * 3.3
	
```

**主程序 main.c**

```c
// ADC1 初始化
Dri_ADC1_Init();
// ADC1 启动转换
Dri_ADC1_Start();

// 死循环， 不断打印测得电压值
while (1)
{
    // 打印电压值， 保留两位小数
    printf("Voltage: %.2lf V \n", Dri_ADC1_GetVoltage());
}
```

**ADC 相关HAL库函数：**

```
HAL_ADCEx_Calibration_Start()		启动校准
HAL_ADC_Start()		启动转换
HAL_ADC_GetValue()	获取测得的值（DR寄存器的值）
__HAL_ADC_GET_FLAG() 获取ADC相关标志位的值
```

**代码：**

```c
// 启动 ADC 校准， 该函数校准完成后调用结束
HAL_ADCEx_Calibration_Start(&hadc1);
// 启动 ADC 转换
HAL_ADC_Start(&hadc1);

// 等待第一次转换完成
while (__HAL_ADC_GET_FLAG(&hadc1, ADC_FLAG_EOC) == RESET)
    ;

while (1)
{
    printf("Value: %d;  Voltage: %.2lf V \n", HAL_ADC_GetValue(&hadc1), HAL_ADC_GetValue(&hadc1) * 3.3 / 4095);
    HAL_Delay(1000);
}
```
