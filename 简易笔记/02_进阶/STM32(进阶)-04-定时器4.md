## 2. 系统定时器

### 2.1 概述

系统定时器一般用于操作系统，用于产生时基，维持操作系统的心跳。SysTick定时器除了能服务于操作系统之外，还能用于其它目的：如作为一个闹铃，用于测量时间等。

系统定时器是一个24bit的向下**递减**的计数器 ，自动重装载。

### 2.2 相关寄存器

| 寄存器名称    | 说明             | 相关控制位/标志位                                            |
| ------------- | ---------------- | ------------------------------------------------------------ |
| SysTick->CTRL | 控制和状态寄存器 | CLKSOURCE：时钟来源，0表示AHB/8; 1表示AHB<br>TICKINT: 中断使能<br>ENABLE: 计数使能<br>COUNTFLAG: 计数到0置位 |
| SysTick->LOAD | 重装载寄存器     | 24bit有效位，从这个数开始到计数                              |
| SysTick->VAL  | 当前值寄存器     | 24bit有效位，记录当前计数的值                                |

> 弱函数 HAL_IncTick() 每隔 1ms 被调用1次。

```c
// 重定义 SysTick 触发中断后调用的弱函数
void HAL_IncTick(void)
{
  // 保证 HAL_Delay 能够正常工作
  uwTick += uwTickFreq;

  // 每调用1000次该弱函数，LED2 翻转一次
  if (uwTick % 1000 == 0) {
    HAL_GPIO_TogglePin(LED2_GPIO_Port, LED2_Pin);  // 翻转 LED2
  }
}
```

### 2.4 案例： SysTick 中断方式实现延时函数工具类

#### 代码实现

```c
// 定义全局变量，用作延时的技术, 每隔1ms就递减1次,减到0为止
uint16_t g_ms_cnt = 0;


void Dri_SysTick_Delay_ms(uint16_t ms)
{
    // 赋值给延时的计数变量
    g_ms_cnt = ms;

    // 等待 g_ms_cnt 减到0为止
    while (g_ms_cnt > 0)
        ;
}

// 定义 SysTick 的 中断服务函数
void SysTick_Handler(void)
{
    // 延时计数递减
    if (g_ms_cnt > 0)
    {
        g_ms_cnt--;
    }
}
```





## 3. 基本定时器

### 3.1 概述

基本定时器TIM6和TIM7各包含一个16位自动装载计数器，由各自的可编程预分频器驱动。

这个2个基本定时器只能向上计数，由于没有外部IO，所以只能计时，不能对外部脉冲进行计数。

### 3.1 功能框图和功能描述

![%E5%9F%BA%E6%9C%AC%E5%AE%9A%E6%97%B6%E5%99%A8%E5%8A%9F%E8%83%BD%E6%A1%86%E5%9B%BE.png](https://p.sda1.dev/22/183938373451ec5aaa5ce3b21b54de4e/基本定时器功能框图.png)

**时钟来源：**

```
基本定时器时钟来源只有系统时钟， 只要 APB1 进行大于1的分频，TIMxCLK = APB1 * 2;
当前 APB1CLK = 36MHz, TIMxCLK = 72MHz
```

**时基单元：**

```
1. PSC 预分频器， 对 CK_PSC（等于TIMxCLK） 进行预分频产生 CK_CNT（计数器时钟）
2. CNT 计数器，向上计数，计到与自动重装载值相同，下一个周期溢出（触发更新事件中断）
3. ARR 自动重装载寄存器，分为预加载寄存器和影子寄存器，影子寄存器与CNT比较
```

### 3.3 相关寄存器

| 寄存器名称 | 描述                | 相关控制位/标志位                           |
| ---------- | ------------------- | ------------------------------------------- |
| CR1        | 控制寄存器1         | ARPE：自动重装载预装载使能<br>CEN：计数使能 |
| DIER       | DMA或中断使能寄存器 | UIE：更新中断使能                           |
| PSC        | 预分频器            | 16bit，这里的数值+1 作为与分频值            |
| ARR        | 自动重装载寄存器    | 16bit                                       |
| CNT        | 计数器              | 16bit                                       |
| SR         | 状态寄存器          | UIF: 更新中断标志位，需要软件清除           |

## 4. 通用定时器

### 4.1 概述

通用定时器有4个分别是：TIM2、TIM3、TIM4、TIM5；它们拥有基本定时器所有功能，并增加如下功能：

（1）多种时钟源。

（2）向上计数（加）、向下计数（减）、向上/向下（先加后减）。

（3）输入捕获。

（4）输出比较。

（5）PWM生成。

（6）支持针对定位的增量（正交）编码器和霍尔传感器电路。

### 4.2  功能框图和功能描述

![%E9%80%9A%E7%94%A8%E5%AE%9A%E6%97%B6%E5%99%A8%E5%8A%9F%E8%83%BD%E6%A1%86%E5%9B%BE.png](https://p.sda1.dev/22/f112793fbdf8b8ca8f4406fbc471d21a/通用定时器功能框图.png)

#### ① 时基单元（同基本寄存器）

```
预分频器寄 (TIMx_PSC) 
自动重装载寄存器 (TIMx_ARR) 
计数器寄存器(TIMx_CNT) 
```

#### ② 3种时钟源

```
1. 内部时钟源（通基本定时器）
2. 外部时钟源模式1：每个定时器有4个输入通道，通道1和通道2可以作为时钟信号源
3. 外部时钟源模式2：每个定时器的ETR引脚输入作为时钟信号源
```

#### ③ 3种计数模式

```
1. 向上计数模式（同基本定时器）
2. 向下计数模式
3. 中央对齐模式（先向上再向下）
```

| TIM3   | PA6/PB4/PC6  | PA7/PB5/PC7 | PB0/PC8  | PB1/PC9  | PD2          |

![%E9%80%9A%E7%94%A8%E5%AE%9A%E6%97%B6%E5%99%A8%E6%A1%88%E4%BE%8B1%E5%8E%9F%E7%90%86%E5%9B%BE.png](https://p.sda1.dev/22/f84784e96c6c0aa165b7a82856d1e69e/通用定时器案例1原理图.png)

#### ②  PWM 介绍

```
PWM: Pulse-width modulation, 脉冲宽度调制
惯性：被控制的电路要有一定的惯性，电路中负载的状态不会发生突变，比如电机断电了不会立即停止
周期：连续的两个上升沿或连续的两个下降沿之间的宽度（时间），用 T 表示
频率：周期的倒数，1s内有多少个周期
占空比：每个周期中高电平占比
```

#### ③ 通用定时器的输出比较

TIMx_CCMR1寄存器中的 OC1M[2:0] 可以配置通道1的 8 种输出比较模式：

| OC1M值 | 描述                       | 行为                                                         |
| ------ | -------------------------- | ------------------------------------------------------------ |
| 000    | 冻结模式                   | CNT和CCR比较结果不影响输出。                                 |
| 001    | 匹配时输出高电平(有效电平) | 当CNT=CCR，输出有效电平，再不改变。                          |
| 010    | 匹配时输出低电平(无效电平) | 当CNT=CCR，输出无效电平，再不改变。                          |
| 011    | 匹配时输出翻转             | 当CNT=CCR，则翻转输出。高->低，低->高。<br>输出结果是一个方波，频率为计数器的溢出频率的一半，占空比为 50% |
| 100    | 强制输出低电平             | 强制输出为无效电平，不受到CNT和CCR比较结果影响。             |
| 101    | 强制输出高电平             | 强制输出为有效电平，不受到CNT和CCR比较结果影响。             |
| 110    | PWM模式1                   | 向上计数时，当CNT < CCR1时输出有效电平，反之无效电平;  <br>向下计数时，当CNT > CCR1时输出无效电平，反之输出有效电平。 |
| 111    | PWM模式2                   | 向上计数时，当CNT < TIM时输出无效电平，反之输出有效电平；<br>向下计数时，当CNT > CCR1时输出有效电平，反之输出无效电平。 |

> 注意：这里推荐使用 PWM模式1！
>
> 默认高电平是有效电平！

#### ③ 寄存器方式实现

`Driver_TIM5.c` 驱动程序：

```
初始化函数：
	1. 对TIM5、GPIOA时钟使能
	2. 设置TIM5_CH2(PA1)为复用推挽输出
	3. 设置TIM5时基单元
	   3.1 设置CNT计数模式为向上计数（默认值）
```

#### ② 触发输入和从模式



![%E9%80%9A%E7%94%A8%E5%AE%9A%E6%97%B6%E5%99%A8%E5%8A%9F%E8%83%BD%E6%A1%86%E5%9B%BE-%E8%A7%A6%E5%8F%91%E6%A8%A1%E5%BC%8F%E5%92%8C%E4%BB%8E%E6%A8%A1%E5%BC%8F.png](https://p.sda1.dev/22/dfed24fbc3dfa1b42073dba5b4eff8e6/通用定时器功能框图-触发模式和从模式.png)

**两种触发信号：**

1. 触发输入信号（TRGI）
   从外部或内部输入，触发本定时器的一些动作（如复位），此时**本定时器**处于主从模式中的**从模式**。
   
2. 触发输出信号（TRGO）

   本定时器输出到其他定时器或外设，此时**本定时器**处于主从模式中的**主模式**。

**触发输入信号选择： **

SMCR 寄存器的 TS位 (3个bit):

```
000：内部触发0(ITR0)，TIM1 
001：内部触发1(ITR1)，TIM2 
010：内部触发2(ITR2)，TIM3 
011：内部触发3(ITR3)，TIM4 

100：TI1的边沿检测器(TI1F_ED) 

101：滤波后的定时器输入1(TI1FP1) 
110：滤波后的定时器输入2(TI2FP2) 

111：外部触发输入(ETRF) 
```

每个定时器的连接是定死的，不可更改

| 从定时器 | ITR0 (TS = 000) | ITR1 (TS = 001) | ITR2 (TS = 010) | ITR3 (TS = 011) |
| -------- | --------------- | --------------- | --------------- | --------------- |
| TIM2     | TIM1            | TIM8            | TIM3            | TIM4            |
| TIM3     | TIM1            | TIM2            | TIM5            | TIM4            |
| TIM4     | TIM1            | TIM2            | TIM3            | TIM8            |
| TIM5     | TIM2            | TIM3            | TIM4            | TIM8            |

**从模式选择（触发后做什么操作）：**

SCMR 寄存器的 SMS 位（3个bit）：

```
000：关闭从模式 – 如果CEN=1，则预分频器直接由内部时钟驱动。
001：编码器模式1 – 根据TI1FP1的电平，计数器在TI2FP2的边沿向上/下计数。
010：编码器模式2 – 根据TI2FP2的电2平，计数器在TI1FP1的边沿向上/下计数。
011：编码器模式3 – 根据另一个信号的输入电平，计数器在TI1FP1和TI2FP2的边沿向上/下计数。
100：复位模式 – 选中的触发输入(TRGI)的上升沿重新初始化计数器，并且产生一个更新寄存器的信号。
101：门控模式 – 当触发输入(TRGI)为高时，计数器的时钟开启。一旦触发输入变为低，则计数器停止(但不复位)。计数器的启动和停止都是受控的。
110：触发模式 – 计数器在触发输入TRGI的上升沿启动(但不复位)，只有计数器的启动是受控的。
111：外部时钟模式1 – 选中的触发输入(TRGI)的上升沿驱动计数器。
```

> 注：我们这里使用复位模式，编码器模式先不用关注。

#### ③ PWM 输入模式



![%E9%80%9A%E7%94%A8%E5%AE%9A%E6%97%B6%E5%99%A8%E5%8A%9F%E8%83%BD%E6%A1%86%E5%9B%BE-PWM%E8%BE%93%E5%85%A5.png](https://p.sda1.dev/22/52f9651ceebae7d6b107308817fc446b/通用定时器功能框图-PWM输入.png)

**PWM 输入模式是输入捕获模式和触发输入模式的一个特例，与普通输入捕获有以下区别：**

```
● 两个ICx信号被映射至同一个TIx输入, 这2个ICx信号为边沿有效，但是极性相反。
● 其中一个TIxFP信号被作为触发输入信号，而从模式控制器被配置成复位模式。
● 配置CCMR1寄存器中的 CC1S、CC2S，实现 IC1 和 IC2 连接同一个CH引脚。
● 图中TI1FP1的极性选择通过CCER寄存器中CC1P配置；TI1FP2的极性选择通过CCER寄存器中CC2P配置。
● 由于只有TI1FP1和TI2FP2连到了从模式控制器，所以PWM输入模式只能使用CH1/CH2信号。
```

| CCR2                          | 捕获比较寄存器2      | 16bit，对应CC2通道<br/>同CCR1                                |
| CCR3                          | 捕获比较寄存器3      | 16bit，对应CC3通道<br/>同CCR1                                |
| CCR4                          | 捕获比较寄存器4      | 16bit，对应CC4通道<br/>同CCR1                                |
| <font color="red">BDTR</font> | 刹车和死区寄存器     | MOE: 主输出使能                                              |

### 5.4 案例：输出有限个周期的PWM波

#### ① 项目需求和硬件电路

需求：

```
输出5个周期的PWM波，频率2Hz，观察发光二极管闪烁5次，或者用示波器观察波形。
```

思路：

```
使用高级定时器的重复计数器，当重复计数器溢出时触发更新中断，更新中断中停止定时器工作。重复计数器寄存器的值设置为4，即可输出5个周期的PWM波，发光二极管会闪烁5次。
```

硬件电路：

```
TIM1 的 CH1 引脚是 PA8，刚好连接 LED3
```

#### ② 寄存器方式实现

**TIM1 驱动程序：**

```
Driver_TIM1_Init 初始化函数：	
	1. 对 TIM1、GPIOA 时钟使能
	2. 设置 TIM1_CH1（PA8）为复用推挽输出
	3. TIM4 时基单元设置
		3.1 设置计数器向上计数(默认值)
		3.2 设置PSC值为7199，实现100us计1个数
		3.3 设置ARR值为4999，实现500ms溢出一次
	4. TIM4_CH1 输出比较设置
		4.1 设置TIM4的CH1为输出比较（CCMR1.CC1S=00，默认值）
		4.2 设置TIM4_CH1的输出比较模式是PWM模式1（CCMR1.OC1M=110）
		4.3 设置TIM4_CH1输出极性:有效电平为高电平(CCER.CC1P=0，默认值)
		4.4 设置TIM4_CH1输出使能（CCER.CC1E=1）
		4.5 设置TIM4主输出使能(BDTR.MOE=1)
		4.6 设置CCR1的值为2500，实现输出PWM的占空比是50%
	5. TIM4 重复计数器，RCR=4,实现CNT溢出5次产生1次更新事件
	6. TIM5 中断和更新事件设置
		6.1 使能TIM4的更新中断（DIER.UIE=1）
		6.2 软件方式主动产生一次更新事件(EGR.UG=1)
	7. NVIC设置

Driver_TIM1_Start 函数：
	开启计数使能


Driver_TIM1_Stop 函数：
	关闭计数使能

中断向量服务程序 TIM1_UP_IRQHandler：
	1. 清除更新中断标志位（SR.UIF）
	2. 关闭计数使能
	
```
