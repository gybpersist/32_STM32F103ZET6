## 第 7 章 STM32 的中断系统

### 7.1 中断概述

#### ① STM32 的中断

STM32F103系列支持 70 个中断：

```
1. 内核中断 10 个，中断来源是内核。
2. 外部（外设）中断 60 个，中断来源是片上外设或GPIO引脚。
```

#### ② STM32 中断体系结构

![%E4%B8%AD%E6%96%AD.png](https://p.sda1.dev/22/b0486d72352e7fff8e385fc11a9867ea/中断.png)

> 注：STM32F103ZE 是非互联网产品，没有以太网环唤醒，所以 EXTI 与 NVIC 之间有 19 条线

#### ③ 中断来源

```
1. 内核
2. 片上外设
3. EXIT（GPIO引脚提高触发信号）
```

> 注：外设中断和EXTI中断统称为外部中断。

#### ④ NVIC 嵌套向量中断控制寄存器和中断优先级

```
1. 先比较抢占(Group)优先级。抢占优先级高的可以打断抢占优先级低的。
2. 若抢占优先级一样，再比较响应(Sub)优先级。但是响应优先级不会导致中断嵌套。
3. 若两个优先级都相同，看中断向量表中的中断号 
```

> 注意：优先级和中断号都是数字小的优先！

| 分组  | **抢占优先级（group）** | **响应优先级（sub）** |
| ----- | ----------------------- | --------------------- |
| **0** | 4位 取值范围：0-15      | 0位 取值范围：0       |
| **1** | 3位 取值范围：0-7       | 1位 取值范围：0-1     |
| **2** | 2位 取值范围：0-3       | 2位 取值范围：0-3     |
| **3** | 1位 取值范围：0-1       | 3位 取值范围：0-7     |
| **4** | 0位 取值范围：0         | 4位 取值范围：0-15    |
使用 SCB->AIRCR 寄存器设置抢占优先级占多少位，10~8位：
```
0b011	抢占优先级4位		
0b100	抢占优先级3位
0b101	抢占优先级2位
0b110	抢占优先级1位
0b111	抢占优先级0位		
```

#### ② 寄存器方式实现

**Int_Key.c**

```
初始化函数：
	1. 时钟使能
		1.1 对 GPIOF 时钟使能
		1.2 对 AFIO 时钟使能
	2. GPIO 引脚设置，将 PF8 设置为上拉输入
	3. AFIO 设置，EXTI8 选择 PF8
	4. EXTI 设置	
	   4.1 设置下降沿触发 (EXTI->FTSR 中的 TR8 控制位)
	   4.2 设置开放EXTI8 (EXTI->IMR 中的 MR8 控制位)
	5. NVIC 设置
	   5.1 设置抢占优先级有多少位（全局设置）
	   5.2 使能 EXTI9_5 中断向量
	   5.3 设置 EXTI9_5 中断向量的优先级
	
中断服务函数：
	1. 判断请求中断是否是EXTI8 (EXTI->PR 中断 PR8 标志位)
	2. 清除 PR 寄存器中的标志位
	3. 消抖处理
	4. 调用弱函数
```

**main.c**

```
1. 初始化LED、Key
2. 重定义SW3按下后所调用的弱函数
```

## 附录

### 寄存器名称

```
RCC:	复位和时钟寄存器，Reset and Clock Control
GPIOx:	通用输入输出x寄存器，General-Purpose Input/Output 
AFIO:	复用功能输入输出寄存器，Alternate Function Input/Output
EXTI:	外部中断寄存器，External Interrupt
NVIC:	嵌套向量中断控制器, Nested Vectored Interrupt Controller
```

```
AHB:	Advanced High-performance Bus (高性能总线)
APB:	Advanced Peripheral Bus Bus (高级外设总线)
FSMC:	Flexible Static Memory Controller (灵活静态存储器控制器)
DMA:	Direct Memory Access (直接存储访问)
HSI:	High Speed Internal oscillator (高速内部时钟)
HSE:	High Speed External Oscillator/Clock (高速外部时钟 )
PLL:	Phase Locked Loop (锁相环/倍频器)
LSI:	Low Speed Internal (低速内部时钟)
LSE:	Low Speed External oscillator (低速外部时钟)
HAL:  	Hardware Abstraction Layer (硬件抽象层)
GPIO:	General-Purpose Input/Output (通用输入输出)
CMSIS:	Cortex Microcontroller Software Interface Standard (Cortex 微控制器软件接口标准 )
AFIO:	Alternate Function I/O (替代功能输入输出)
```
